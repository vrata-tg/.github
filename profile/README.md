# Врата AI

**Claude, GPT и другие модели через API — с оплатой в рублях.**

Для разработки, учёбы и собственных проектов. Подключайте модели к привычным инструментам, пополняйте баланс и платите только за использованные токены — без ежемесячной подписки.

[Получить API-ключ](https://vrata.tg/bot) · [Сайт](https://vrata.tg) · [Плагин для bb](https://github.com/vrata-tg/vrata-bb-plugin)

## Как начать

1. Откройте [бота в Telegram](https://vrata.tg/bot) — там доступны модели, цены, баланс и API-ключи.
2. Создайте API-ключ и подключите его к своему инструменту для работы с ИИ.
3. Выберите модель и отправьте первый запрос.

## Врата AI для bb

[Наш плагин для bb](https://github.com/vrata-tg/vrata-bb-plugin) позволяет работать с моделями «Врат» напрямую из bb.

```bash
bb plugin install npm:@vrata-ai/bb-plugin
```

После установки выберите провайдера **Врата AI** и укажите свой API-ключ.
